# Zero Trust Security Architecture

**Project Type:** Independent Cybersecurity Project  
**Status:** In Progress  
**Environment:** Fictional organisation – Nordic Design Solutions  
**Focus:** Identity and Access Management, Least Privilege and Access Security

## 1. Project Overview

This project explores the design of a Zero Trust Security Architecture for a fictional company called Nordic Design Solutions, a Denmark-based design and consulting organisation with 50 employees.

The company uses Microsoft 365, cloud-based file storage, employee laptops and remote working arrangements.

The objective is to identify security weaknesses in its existing access management approach and propose improvements based on Zero Trust principles.

## 2. Business Scenario

Nordic Design Solutions has three departments:

- Finance
- Design
- IT

Employees access business applications and company information from both office and remote locations.

The organisation currently faces several security challenges, including inconsistent Multi-Factor Authentication (MFA), excessive user permissions, delayed account deactivation and insufficient access reviews.

## 3. Project Objectives

The main objectives are:

1. Understand the organisation's existing security environment.
2. Identify potential identity and access management risks.
3. Design a Zero Trust security architecture.
4. Recommend appropriate authentication and access controls.
5. Apply the principle of least privilege.
6. Develop an access review and security improvement plan.

## 4. Identified Security Challenges

| Security Challenge | Potential Risk |
|---|---|
| MFA not consistently enforced | Account compromise |
| Excessive user permissions | Unauthorised access to sensitive data |
| Delayed account deactivation | Former employees retaining access |
| Inconsistent remote access checks | Untrusted devices accessing company resources |
| Shared administrative accounts | Reduced accountability |
| Infrequent access reviews | Unnecessary permissions remaining active |

## 5. Zero Trust Principles

The proposed architecture will follow three core principles:

- **Verify Explicitly:** Verify user identity, device security and access conditions.
- **Use Least Privilege Access:** Provide only the permissions required for each job role.
- **Assume Breach:** Design security controls to limit the impact of compromised accounts or devices.

## 6. Proposed Security Improvements

The project will investigate the following security controls:

- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Microsoft Entra ID identity management
- Privileged access management
- Device compliance checks
- Regular user access reviews
- Account lifecycle management
- Security monitoring and logging

These are proposed design recommendations, not controls already implemented in a live company.

## 7. Project Deliverables

The planned deliverables include:

1. Business and security environment assessment.
2. Zero Trust architecture diagram.
3. User access control matrix.
4. Security risk assessment.
5. Recommended security implementation roadmap.
6. Final project report and lessons learned.

## 8. Learning Outcomes

Through this project, I aim to develop practical knowledge of Zero Trust architecture, identity management, access controls, security risk assessment and cybersecurity documentation.
